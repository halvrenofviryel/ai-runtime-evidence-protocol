# Changelog

## v0.2.0-beta.1 — prepared, unpublished

* First-party Python reference producer/library and four emit commands with
  frozen v0.2 integrity, pure Ed25519 signatures and chain continuation.
* Runnable Decision → issuer dispatch → receiver receipt → Execution → Effect
  local example, committed fixtures and failure/qualification variants.
* Structured lifecycle reconciliation with explicit missing, failure,
  unevaluated and indeterminate states, separate from record assurance classes.
* Consolidated normative specification, existing normative class text,
  developer quickstart, beta readiness and release-stage contract.
* AD-17 raw JSON admission and r3 exact profile-basis evaluation in Python/Node
  adapters. Corrected observer resolution prerequisites in the beta path.
* Prior W1 Erratum-8 evaluator work consolidated into the repository with exact
  source provenance; no new external interoperability claim.
* CI-equivalent reproduction and negative controls; preserved v0.1, frozen v0.2
  byte constructions, historical measurements and external evidence.
* AD-01's earlier alpha/migration-tooling discrepancy recorded and sequencing
  corrected; migration tooling deferred, stable independence standards retained.

See [release notes](spec/airep/v0.2/RELEASE_NOTES_BETA_1.md) and the
[work report](reports/beta-2026-09-08/WORK_REPORT_TR.md) for measured evidence,
defects, source inventory, and exact changes. No tag or release was published
as part of preparation.
