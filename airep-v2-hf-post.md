# AIREP arXiv v2 is public

AIREP arXiv v2 is now public. The revision centers the protocol on four correlated runtime-evidence artifact families:

**Decision → Control → Execution → Effect**

It also specifies bounded **AIREP-Core / AIREP-Authenticated / AIREP-Witnessed** assurance, deterministic wire and integrity construction, and structured lifecycle reconciliation that preserves failure, missing, not-evaluated and indeterminate states rather than turning absent evidence into success.

The current implementation target, **v0.2.0-beta.1**, remains experimental and is not stable. Independent implementation evidence remains scoped to the version and role measured; no same-version third-party v0.2 producer-to-consumer interoperability result has been established. The Hermes and LightEval work discussed in the paper consists of non-normative, first-party integration exercises—not external adoption, endorsement or interoperability evidence.
