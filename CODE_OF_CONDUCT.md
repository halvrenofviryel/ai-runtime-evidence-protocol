# Code of Conduct

AIREP is a technical format project. This code exists so that review of it stays about the work.

## The standard

- Be precise, be kind, and assume good faith.
- Critique the record, the schema, the verifier, or the claim — not the person.
- Disagreements about the format are resolved by what the conformance vectors and the threat model
  actually demonstrate, not by seniority, affiliation, or authority.
- Welcome adversarial review, independent implementations, and "this claim exceeds its evidence"
  findings — they are the point.

## Unacceptable

Harassment, personal attacks, discriminatory or demeaning language, deliberate intimidation, sharing
others' private information, and sustained disruption of technical discussion.

## Scope

Applies in all project spaces — issues, pull requests, discussions, and any communication that
represents the project.

## Enforcement

Report concerns privately to **founder@phionyx.ai**. Reports are handled discreetly. Maintainers may
edit, hide, or remove contributions that violate this code, and may block repeat or severe
violators. Enforcement aims to be proportionate and is explained where possible.

This code is adapted in spirit from the Contributor Covenant; it is intentionally short.
